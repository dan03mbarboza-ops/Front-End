# Minha API

Este pequeno projeto é um pequeno projeto MVP, desenvolvimento como uma forma de praticar o Back-End e o Front-End, com a tematica de livros.

O objetivo é criar um pequeno cadastro de livros em um site.

---
## Como executar 

OBS: O Front-End só funciona se o Back-End esteja em execução com a API rodando no localhost, se o usuário tentar executar o Front-End primeiro, o site irá dar erro.

Clique no arquivo index.html, e assim, abrirá uma página automaticamente no navegador com o projeto em execução.
